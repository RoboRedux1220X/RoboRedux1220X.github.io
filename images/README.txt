This folder is where your real photos and logo go.

The website currently uses gray placeholder boxes instead of images so the
site works right away, before you've added anything. Each placeholder box
has a comment right above it in the HTML file telling you the exact
filename it's expecting and the exact line of code to swap in.

Suggested files to add here:
  logo.png          - your team logo (used in the top navigation bar)
  hero.jpg           - main photo on the home page
  gallery-1.jpg       - photo on the home page "Who We Are" section
  gallery-2.jpg       - photo in the home page "On the Field" strip
  gallery-3.jpg       - photo in the home page "On the Field" strip
  gallery-4.jpg       - photo in the home page "On the Field" strip
  cad-render.jpg      - robot or CAD photo on the About page
  (add your own images for the "Meet the Team" cards on the About page)

You are not required to use these exact names — if you use a different
filename, just make sure the "src" in the matching <img> tag matches it
exactly, including capitalization and file extension (.jpg vs .png).

Once you delete this file or add images, you can remove this README.txt —
it's just here so the empty folder isn't blank when you open the project.
